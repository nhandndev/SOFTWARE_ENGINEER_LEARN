# Chặng 3 — API & Security

Tài liệu chuẩn bị sẵn, không đồng nghĩa đã mở hoặc đạt module. Con trỏ học vẫn theo `05_TIEN_DO.md`.

- [M3-1: REST API best practices](M3_1_REST_Best_Practices/README.md): chuẩn hóa hợp đồng, không học lại cách viết Controller từ đầu.
- [M3-2: Security Core](M3_2_Security_Core/README.md): filter chain, xác thực/phân quyền, User/Role/BCrypt, CSRF/CORS; bốn lesson có đề và bài giải.

- [M3-3: JWT](M3_3_JWT/README.md): bốn lesson, từ chữ ký đến refresh rotation, phân quyền và kiểm thử.
- [M3-4: OAuth2 / OIDC](M3_4_OAuth2_OIDC/README.md): ba lesson, Google Login và ánh xạ tài khoản nội bộ.

- [M3-5: External API Client & OpenAPI](M3_5_OpenAPI_Client/README.md): bốn lesson về WebClient, resilience, hợp đồng OpenAPI và tài liệu Bearer JWT.

Các bộ bài trên là tài liệu soạn sẵn, không phải bằng chứng đã hoàn tất deliverable.

Trước khi ghép ví dụ giữa các module: đọc [quy ước tích hợp API, Security và lỗi](README_TICH_HOP_CONTRACT.md).
