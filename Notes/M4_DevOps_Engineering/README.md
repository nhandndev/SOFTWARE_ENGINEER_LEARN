# Chặng4 · DevOps & Engineering

- [M4-2 · GitHub Actions CI](M4_2_GitHub_Actions_CI/README.md): bốn lesson từ sự kiện và runner đến Maven gate, GHCR và chẩn đoán workflow.

- [M4-4 · Logging & Hexagonal](M4_4_Logging_Hexagonal/README.md): bốn lesson về log an toàn, requestId/MDC, structured JSON và Ports & Adapters; mỗi lesson có đề, bài giải và rubric.

CI ở M4-2, TDD/coverage ở M4-3, logging/architecture ở M4-4; không nhồi Kubernetes/AWS deployment vào Docker cơ bản.
