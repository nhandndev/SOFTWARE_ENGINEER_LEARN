## Giả định chung

Đây là schema **minh họa**, không khẳng định đang chạy trong `shopcore`. Giả sử không có trigger, rule, concurrent transaction hay lỗi ngoài điều đề nêu:

```sql
CREATE TABLE categories (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE products (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sku TEXT NOT NULL UNIQUE,
    name TEXT NOT NULL,
    price NUMERIC(12,2) NOT NULL CHECK (price > 0),
    category_id BIGINT REFERENCES categories(id)
);
```

`products` đang có `(id=10, sku='BK-01', name='Java Book', price=120.00, category_id=1)`. Ứng dụng giả định có PostgreSQL đang nhận kết nối, trừ khi câu hỏi nói ngược lại. Không suy ra ID sequence kế tiếp từ dữ liệu bảng.
