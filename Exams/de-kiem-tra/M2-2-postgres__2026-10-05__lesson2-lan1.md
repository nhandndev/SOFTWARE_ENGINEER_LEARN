## Schema và dữ liệu dùng chung

Đây là schema giả định của đề, **không khẳng định đã chạy trong `shopcore`**. Giả sử không có trigger, rule hay transaction khác đang can thiệp.

```sql
CREATE TABLE categories (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE products (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sku TEXT NOT NULL UNIQUE,
    name TEXT NOT NULL,
    price NUMERIC(12,2) NOT NULL CHECK (price > 0),
    category_id BIGINT REFERENCES categories(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    attributes JSONB
);
```

**categories**

| id | name |
|---:|---|
| 1 | Books |
| 2 | Electronics |

**products**

| id | sku | name | price | category_id |
|---:|---|---|---:|---:|
| 10 | BK-01 | Java Book | 120.00 | 1 |
| 11 | EL-01 | Mouse | 300.00 | 2 |
| 12 | BK-02 | SQL Book | 80.00 | 1 |

## Câu 3 - `UPDATE`: một dòng, hai dòng hay cả bảng? (5đ)

Với **ba lệnh độc lập** dưới đây, mỗi lệnh tác động id nào, giá mới là bao nhiêu và count thành công là mấy?

```sql
-- A
UPDATE products SET price = price + 10 WHERE id = 10;

-- B
UPDATE products SET price = price + 10 WHERE category_id = 1;

-- C
UPDATE products SET price = price + 10;
```

Giải thích vì sao việc bỏ `WHERE` ở C nguy hiểm khi chỉ định sửa một Product.

## Câu 5 - `DELETE 0` khác lỗi FK (5đ)

Ba lệnh **độc lập**:

```sql
-- A
DELETE FROM products WHERE id = 12 RETURNING id, sku;

-- B
DELETE FROM categories WHERE id = 999 RETURNING id;

-- C
DELETE FROM categories WHERE id = 1 RETURNING id;
```

Với mỗi lệnh: xóa được mấy dòng, `RETURNING` có gì (nếu thành công), hay bị lỗi gì? Giải thích riêng vì sao C không đơn thuần là `DELETE 0`.

## Câu 6 - Trùng SKU: `DO NOTHING` có nghĩa gì? (5đ)

```sql
INSERT INTO products (sku, name, price, category_id)
VALUES ('BK-01', 'Another Java Book', 90.00, 1)
ON CONFLICT (sku) DO NOTHING
RETURNING id;
```

Có dòng mới không? `RETURNING` có tự trả id của Product `BK-01` cũ không? Nếu yêu cầu nghiệp vụ là **báo lỗi SKU đã tồn tại**, có nên dùng `DO NOTHING` ở đây không? `DO NOTHING` có bỏ qua lỗi giá âm/FK sai không?

## Câu 7 - Phân biệt dữ liệu trả về và lỗi constraint (5đ)

Hai lệnh **độc lập**:

```sql
-- A
UPDATE products
SET price = price + 10
WHERE id = 11
RETURNING id, price;

-- B
UPDATE products
SET price = -20
WHERE id = 11
RETURNING id, price;
```

Lệnh A trả gì trong `RETURNING`? Lệnh B có thể trả một dòng thành công với giá `-20` không? Phân biệt rõ `UPDATE 0` với lệnh bị constraint từ chối.
