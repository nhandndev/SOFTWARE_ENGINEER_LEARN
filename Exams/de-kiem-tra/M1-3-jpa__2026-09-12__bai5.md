## Cau 2 - createdAt vs updatedAt (3d)

Phan biet `createdAt` va `updatedAt`.

Khi tao moi entity, 2 field nay co gia tri nhu the nao? Khi update entity, field nao thay doi?

**Tra loi:** khi mới tạo , createdAt có giá trị là ngay hiện tại thời điểm , updatedAt không có giá trị ( nhưng mà thường tôi cho nó trùng so với createdAt ) rồi sau đó là createdAt là k dc update nữa mà chỉ có updatedAt mới dc update value . Khi update thì updatedAt được thay đổi

## Cau 9 - Code mini (4d)

Viet pseudo-code cho `BaseEntity` co:

- `@MappedSuperclass`
- `@EntityListeners(AuditingEntityListener.class)`
- `createdAt`
- `updatedAt`

Sau do viet `Product extends BaseEntity`.

**Tra loi:**
Getter
@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
public abstract class BaseEntity {

    @CreatedDate
    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @LastModifiedDate
    @Column(nullable = false)
    private LocalDateTime updatedAt;
}
```

```java
@Entity
@Table(name = "products")
@Getter
@Setter
@NoArgsConstructor
public class Product extends BaseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true)
    private String sku;

    @Column(nullable = false)
    private String name;
}
```
