> Muc tieu module: viet duoc test co y nghia cho `shopcore`, biet chon dung loai test, va giu code de doc ngay tu dau.

1. Lesson 01: JUnit 5 co ban, test mindset va clean test naming.
2. Lesson 02: Mockito cho Service layer.

```text

Khong viet test chi de tang so luong
```
