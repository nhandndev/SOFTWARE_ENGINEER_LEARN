# M2-2 - PostgreSQL thực chiến

M2-1 đã học cách **đọc dữ liệu**. M2-2 học cách **lưu và thay đổi dữ liệu mà không làm hỏng tính đúng đắn**. Học theo bốn lesson, mỗi lesson có đề riêng; không cần làm thêm project mới.

1. [Lesson 01: kiểu dữ liệu và constraint](LESSON_01_KIEU_DU_LIEU_CONSTRAINT.md) - đang học. [Đề Lesson 01](../../../Exams/de-kiem-tra/M2-2-postgres__2026-10-05__lesson1-lan1.md).
2. Lesson 02: `INSERT`/`UPDATE`/`DELETE` an toàn, `WHERE`, `RETURNING`, số dòng bị ảnh hưởng.
3. Lesson 03: transaction `BEGIN`/`COMMIT`/`ROLLBACK` và liên hệ `@Transactional`.
4. Lesson 04: tham số qua JDBC/JPA, kết nối PostgreSQL, identity/sequence và nhận diện VACUUM/autovacuum.

Mỗi bài đi từ ví dụ nhỏ tới cách áp dụng trong backend. Các câu hỏi chấm theo **ý nghĩa và lập luận**, không bắt nhớ toàn bộ cú pháp Java hoặc triển khai capstone trong giai đoạn này. Đáp án nằm riêng trong `Exams/de-kiem-tra/`; bạn có thể yêu cầu chấm từng phần và sẽ có snapshot nhận xét.
