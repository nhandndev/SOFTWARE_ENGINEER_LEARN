## Dữ liệu và schema dùng chung

Đây là dữ liệu giả định cho đề, **không phải schema đã chạy trên `shopcore`**:

```sql
CREATE TABLE categories (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE products (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sku TEXT NOT NULL UNIQUE,
    name TEXT NOT NULL,
    price NUMERIC(12,2) NOT NULL CHECK (price > 0),
    category_id BIGINT REFERENCES categories(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    attributes JSONB
);
```

Giả sử `categories` có `(1, 'Books')`, `(2, 'Electronics')`; `products` có một dòng với `sku='BK-01'`, `price=120.00`, `category_id=1`. Mỗi tình huống ở dưới **độc lập**, không tự cộng dồn dữ liệu giữa các câu.
