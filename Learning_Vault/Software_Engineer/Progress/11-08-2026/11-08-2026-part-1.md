## 2. Việc hôm nay (Dự kiến 3 giờ)
Theo nguyên tắc 30% xem - 70% code, chúng ta sẽ bắt đầu xử lý 2 mục tiêu đầu tiên trong checklist của M0-1:

- **Task 1: Lý thuyết Generics & Lambda (1h)**
  - Đọc tài liệu về Generics: type parameter, bounded type, wildcards (`? extends` / `? super`).
  - Tìm hiểu Functional Interface, cú pháp Lambda, và method reference.
  - *Nguồn tham khảo: Oracle Docs hoặc Baeldung.*

- **Task 2: Code thực hành Result<T> và PageResponse<T> (2h)**
  - Do chưa đến module Git & Maven (M0-5), bạn chỉ cần tạo thư mục `shopcore` và một Java Project cơ bản (hoặc khởi tạo qua IDE).
  - Tạo package `common`.
  - Viết class `Result<T>` (để gói kết quả trả về, ví dụ có success, message, data kiểu T) và `PageResponse<T>` (để gói dữ liệu phân trang) áp dụng Generics vừa học.

## 3. Tại sao là việc đó
Đây là buổi đầu tiên của toàn bộ lộ trình. Generics là nền tảng cốt lõi để bạn có thể viết mã an toàn về kiểu (type-safe) và có thể tái sử dụng. Lambda là bước đệm bắt buộc để học Stream API và Optional trong các buổi tới. Bạn sẽ dùng `Result<T>` và `PageResponse<T>` liên tục trong tất cả các API của dự án `shopcore` sau này.
