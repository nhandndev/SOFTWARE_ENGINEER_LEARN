# ChatGPT Projects va Learning Vault

ChatGPT Projects (vi du AWS, AI Engineer) luu chat, file va instructions tren tai khoan ChatGPT. Chung **khong phai** folder local tren may va setup hien tai khong the tu doc hoac sua noi dung do.

## Dua kien thuc vao vault

1. Mo tung Project tren ChatGPT va chon cac ghi chu/file can luu lau dai.
2. Tai file nguon ve may, hoac dua noi dung chat quan trong thanh file Markdown trong mot folder local rieng cho AWS/AI Engineer.
3. Cho AI duoc phep doc folder local do; yeu cau tong hop, doi chieu ghi chu da co va de xuat noi luu.
4. Dang ky duong dan folder local vao `SYNC_SOURCES.tsv` de lan chay dong bo tiep theo copy file vao `AWS/Imported/` hoac `AI_Engineer/Imported/`.

Voi chat trong Project, ChatGPT co tuy chon luu mot cau tra loi thanh project source; ban cung co the chuyen mot so chat cu vao Project qua menu cua chat. Cac thao tac nay giup to chuc **trong ChatGPT**, khong tu tao file Markdown trong Obsidian. Xem [huong dan Projects chinh thuc](https://help.openai.com/en/articles/10169521-projects-in-chatgpt).

Khong upload `.env`, AWS access key, token hoac tai lieu rieng tu nhay cam chi de dong bo.
